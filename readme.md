# Setup
- rename `env.txt.sample` to `env.txt`, and fill in the values
- `docker-compose up --build` from the root folder to spin up the project

The `bot` container runs `alembic upgrade head` on startup (see `bot/start.sh`),
so the DB schema is created/migrated automatically — no separate command needed.

# Migrations
- Create: `docker-compose run --rm migrate revision --autogenerate -m "added tag to league user"`
- Run: `docker-compose run --rm migrate upgrade head`
- Roll back one: `docker-compose run --rm migrate downgrade -1`
- Current/head: `docker-compose run --rm migrate current` / `docker-compose run --rm migrate heads`

Autogenerated revisions land in `bot/alembic/versions/` (the `migrate` service
mounts it), so always review the generated file before committing. `env.py` runs
with `compare_type` and `compare_server_default` on, so column type and
server-default changes are picked up in addition to added/dropped tables and
columns.
